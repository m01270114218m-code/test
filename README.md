# Im Chat – Independent Flutter Rebuild

هذه الحزمة تحتوي على مشروع Flutter مستقل + الأصول المستخرجة من حزمة التطبيق المرفقة.

## مهم
- هذا ليس السورس الأصلي المستعاد؛ الحزمة تحتوي على كود مترجم.
- تم وضع الأصول الفعلية داخل assets/، مع هيكل Flutter قابل للبناء والتطوير.

## البناء
1. ثبّت Flutter SDK.
2. من جذر المشروع نفّذ flutter pub get.
3. أنشئ ملفات المنصات إن لزم: flutter create .
4. شغّل flutter run أو flutter build apk.
